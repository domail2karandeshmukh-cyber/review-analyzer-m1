# Review Analyzer

A simple Python project that classifies customer reviews as positive, negative, or unknown using basic text rules.

## Purpose
The project demonstrates Python development, testing, Git version control, branching, and collaboration.

## Prerequisites
- Python 3
- Git

## Installation
Clone the repository:

git clone https://github.com/domail2karandeshmukh-cyber/review-analyzer-m1.git

cd review-analyzer-m1

No additional Python packages are required.

## Run the Application
python3 app.py

## Example Input and Output
"Good product" -> positive
"Bad product" -> negative
"Average product" -> unknown

## Run Tests
python3 test_app.py

## Project Structure
- app.py - Review classification code
- test_app.py - Python tests
- README.md - Project documentation
- .gitignore - Excluded files
